Relatório de Orçamento — Hospedagem e Domínio

Este relatório compara opções de hospedagem web e de registro de domínio para publicar a DevNetwork. Os valores são aproximados, de referência, e podem mudar conforme promoções e período de contratação. Antes de contratar, os preços devem ser conferidos nos sites oficiais listados nas fontes.

Opções de hospedagem

1. GitHub Pages (gratuita)

  • Preço: grátis
  • Espaço: até 1 GB por site
  • Largura de banda: limite de referência de 100 GB por mês
  • SSL: HTTPS gratuito incluído
  • Suporte: documentação e fórum da comunidade
  • Observação: hospeda apenas sites estáticos (HTML, CSS e JavaScript)

2. Hostinger — Plano Premium (paga)

  • Preço: cerca de R$ 12 a R$ 15 por mês (valor promocional em contratos longos)
  • Espaço: 100 GB SSD
  • Largura de banda: ilimitada
  • SSL: gratuito incluído
  • Suporte: chat 24 horas, 7 dias por semana
  • Observação: suporta PHP e banco de dados MySQL; domínio grátis no primeiro ano

3. HostGator — Plano P (paga)

  • Preço: cerca de R$ 15 a R$ 20 por mês (valor promocional)
  • Espaço: ilimitado para 1 site
  • Largura de banda: ilimitada
  • SSL: gratuito incluído
  • Suporte: chat, telefone e e-mail 24 horas
  • Observação: suporta PHP e banco de dados MySQL

Opções de domínio

1. devnetwork.com.br — Registro.br

Cerca de R$ 40,00 por ano. Extensão brasileira, ideal para público do Brasil. Exige CPF ou CNPJ.

2. devnetwork.dev.br — Registro.br

Cerca de R$ 40,00 por ano. Extensão brasileira voltada para desenvolvedores, combina com o tema do site.

3. devnetwork.com — registradores internacionais (ex.: Hostinger, GoDaddy)

Cerca de R$ 60 a R$ 90 por ano. Extensão internacional, mais conhecida, útil se o site crescer para fora do Brasil.

A extensão .edu.br não foi considerada porque é reservada para instituições de ensino.

Escolha final e justificativa

Para esta fase do projeto, a escolha é GitHub Pages + domínio devnetwork.com.br, com custo total de cerca de R$ 40 por ano. Como o site ainda é feito só com HTML e CSS, uma hospedagem estática gratuita atende bem: tem HTTPS incluído, publica direto do repositório que a equipe já usa no GitHub e não gera custo mensal. O domínio .com.br é barato, passa confiança para o público brasileiro e pode ser apontado para o GitHub Pages.

Pensando em escalabilidade: uma rede social de verdade vai precisar de login, banco de dados e back-end, o que o GitHub Pages não oferece. Quando o projeto chegar nessa fase, o plano é migrar para a Hostinger Premium, que tem o melhor custo-benefício entre as pagas (mais barata, 100 GB SSD, banco de dados e suporte 24/7), mantendo o mesmo domínio.
